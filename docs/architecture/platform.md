# Core and platform layer

## Text: Shift_JIS everywhere (`src/core/sjis.*`)

Game files, the built-in message table and all text the runtime produces are Shift_JIS (spec 00 §4). Inside
OpenMK95 text stays Shift_JIS (the `sjis` type is a byte string); it is converted only at the edges: UTF-8 for
window captions, message boxes, logs and host file names. The conversion uses a CP932 table
(`src/core/gen/cp932_table.inc`, generated by `tools/gen_cp932.py` from Python's `cp932` codec). Program texts
are written as UTF-8 literals and converted once with `sj::S("…")`.

## Files (`src/core/fsys.*`)

`fsys::setGameDir()` scans the game folder once and indexes its files by a lookup key:

- Names match case-insensitively with Windows semantics: ASCII letters are folded, trail bytes of double-byte
  characters are not (spec 02 §2.2).
- The key is the Unicode form of the name, so a game folder works whether its host file names are UTF-8 (the
  usual case after unpacking on macOS, Windows or a UTF-8 Linux system) or raw Shift_JIS bytes (unpacking LHA
  archives on Linux often keeps them).
- Names from game data are reduced with the byte-wise base-name rule of spec 02 §2.4 (`sj::baseName`), including
  its quirk that a trail byte 0x5C counts as a separator.

## Bitmaps and surfaces (`src/core/gfx.*`)

BMP decoding (palettized, 16/24/32-bit, RLE4/RLE8), 8-bit `Surface`s, `Palette`s, nearest-color matching and the blits of spec 03
§1–§3.

## Font (`src/core/font.*`)

The original draws text with MS P Gothic. OpenMK95 uses the public-domain Shinonome 16-pixel bitmap fonts
(`shnmk16` for double-byte characters, `shnm8x16r` for single-byte ones) with synthetic emboldening, and the
reference metrics of spec 06 §2: line height 18, maximum character width 17 (single-byte characters 9). Window
sizes and positions therefore match the specification's tables. The glyphs are converted to
`src/core/gen/font_data.inc` by `tools/gen_font.py` from the PCF files in `tools/fonts/`.

## Random numbers (`src/core/rng.*`)

The linear congruential generator of spec 01 §6 (state 1 at program start, multiplier 0x000015A400004E35,
output bits 32–62). `rng::rnd(n)` draws nothing when n is 0, as the specification requires.

## Host (`src/platform/platform.*`)

The platform layer wraps SDL2 and offers the runtime what the original got from Windows:

| Area | Interface |
|---|---|
| Window | `plat::init`, `setCaption`, `setFullscreen` (F4 / Alt+Enter); the 640×480 frame is scaled to the (resizable) window, 1× or 2× by default depending on the screen size, `--smooth` for linear filtering |
| Frames | the display module registers a refresh callback; `showFrame()` uploads a composed RGB frame |
| Input | `pumpOS()` reads SDL events into a queue of key and mouse events (`popInput`); keys are Windows virtual-key codes, so the engine's key handling reads like the specification; game controllers are mapped to keys |
| Time | `now()` (milliseconds), `idle()` (about 1 ms), `delay(ms)`, `waitVBlank()` (60 Hz) |
| Dialogs | `messageBox()` for the original's error and confirmation boxes; `waitForDrop()` for choosing a game folder |

### Headless mode and virtual time

`--headless` uses SDL's offscreen video driver, so no window appears. `--virtual-time` replaces the clock with a
counter that advances only when the program idles, delays or waits for a vertical blank: everything that depends
on time (map ticks, message waits, transitions, script timing) then happens at the same virtual moments on every
run, independent of machine speed. `--script FILE` feeds keys and mouse events at given virtual times and takes
screenshots; the command list is in the README.

## Program start (`src/app/main.cpp`)

`main()` parses the options, finds the game folder (argument, folder of the executable, current folder, or a
folder dropped on the start window), performs the start-up checks of spec 01 §2 with the original's messages
(no `.RPG` file, missing `EPARTY.DAT` or `MONSTPIC.DAT`, unreadable game file), loads the databases, builds the
initial party and enters the title screen (`rt::runTitle`).
